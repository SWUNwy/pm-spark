# 框架索引（Frameworks Index）

选框架时先读本文件。只在需要时加载详细框架文件。

## 选择规则

- 默认：1 个主框架 + 1-2 个辅助框架。
- 告诉用户主框架。
- 除非被要求，否则自然融合辅助框架。
- 解释低频框架为何合适。
- 框架冲突时，解释冲突来源并推荐优先级。
